重點速覽

閱讀時間估算約 15–20 分鐘

先看金屬板的瑕疵案例，再用模型圖判斷該收集哪種標註、採用哪種輸出、如何評估。

  • 分類給整張影像的類別，偵測加上位置，分割描述像素區域。
  • 卷積擷取局部特徵，激活增加非線性，池化下採樣。
  • YOLO 直接預測；Faster R-CNN 先找候選區域。
  • IoU 看兩個區域的重疊，mAP 看一批偵測結果。

模型圖與核心知識

電腦視覺（Computer Vision, CV）從影像或影片擷取資訊。以下先看同一張圖在不同任務下會產生什麼輸出。

影像常以高度、寬度、通道表示。輸入可做縮放與正規化，資料增強需對應實際拍攝條件。相鄰影片幀或同一零件的近似影像應按群組切分，避免訓練與驗證集洩漏。

卷積神經網路（Convolutional Neural Network, CNN）藉由局部濾波學特徵。Flatten 攤平成向量而不增加可訓練權重；Vision Transformer（ViT）則把影像區塊當作詞元來做注意力。小樣本時可評估預訓練模型的遷移學習（Transfer Learning）。

精確率（Precision）衡量報警中有多少是真的，召回率（Recall）衡量實際瑕疵抓到多少。分割模型如 U-Net 可輸出像素預測；辨識（Recognition）還可依需求包含身分辨識，與單純的人臉偵測有不同的資料和權限要求。

產線驗收要同時看不同光線下的漏檢、誤報及端到端延遲。影像可能含人臉或其他個資，上線時須管理存取與保存；高風險結果可安排人工覆核。

練習題

第 1 題 · 任務選擇

自編模擬題

要量測照片中每一道刮痕的像素面積，同類刮痕須各自分開。最適合什麼輸出？

  1. 每張圖一個類別
  2. 每道刮痕一個邊界框
  3. 每道刮痕各自的像素遮罩
  4. 所有刮痕共用一張語意類別遮罩

第 2 題 · 架構比較

自編模擬題

辨識一個偵測架構時，哪項線索最能判斷它是典型 Faster R-CNN 類兩階段模型？

  1. 輸入經過正規化
  2. 候選區域先由網路產生，再分類和調整邊界框
  3. 模型輸出帶有分數
  4. 部署時在 GPU 推論

第 3 題 · 指標計算

自編模擬題

預測框和真值框的面積各 40，交集面積為 20。兩框的 IoU 是多少？

  1. 1/4
  2. 1/2
  3. 2/3
  4. 1/3

考前 3 分鐘複習

  • 類別 → 分類；位置 → 偵測；像素 → 分割。
  • 語意分割分像素類別，實例分割還辨同類個體。
  • 卷積算局部特徵，池化做下採樣。
  • Faster R-CNN 先找候選區域。
  • IoU 分母用聯集，重疊區只算一次。
  • 報警過多看精確率，漏掉瑕疵看召回率。

章末解析

第 1 題解析

正確答案 C。實例分割可同時提供精確的像素區域與個體身分。

  1. 分類只能指出整張圖的類別。
  2. 框的面積包含刮痕外的區域。
  3. 獨立遮罩可逐一道量測。
  4. 類別遮罩不區分同類個體。

第 2 題解析

正確答案 B。候選區域階段和區域預測階段分開。

  1. 各類模型都可正規化。
  2. 符合兩階段的工作分工。
  3. 單階段模型也會有分數。
  4. 硬體不能用來判斷模型階段。

第 3 題解析

正確答案 D。聯集面積為 40＋40−20＝60，交集 20 除以 60 等於 1/3。

  1. 1/4 把兩框面積直接相加，重複計入交集。
  2. 1/2 只用單一框作分母。
  3. 2/3 不是交集在聯集中的比例。
  4. 交集 20 除以聯集 60。
