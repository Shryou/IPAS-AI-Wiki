# iPAS 中級 AI 應用規劃師互動圖解學習站

從模型圖理解 L21 的輸入、處理與輸出。網站收錄 3.1 至 3.3，共 11 組自製圖解與九題自編練習。完整 PDF 講義另由首頁索引開啟。

雙擊根目錄的 `index.html` 即可離線瀏覽。模型圖用按鈕切換狀態，首頁預覽可用滑鼠懸停、鍵盤聚焦或點按，解析放在每章最後。停用 JavaScript 時，模型圖依序展開，解析仍可逐題操作。

| 位置 | 用途 |
| --- | --- |
| `index.html` | 首頁、章節卡片和 PDF 索引 |
| `lessons/3-1-nlp.html` | 自然語言處理，也是新增章節的版型 |
| `lessons/3-2-computer-vision.html` | 電腦視覺，含輸出比較、CNN 與 IoU |
| `lessons/3-3-generative-ai.html` | 生成式 AI，含模型家族、去噪和工具查證 |
| `assets/` | 共用樣式與互動 |
| `material/` | 九份圖解精讀 PDF |
| `AGENTS.md` | 可重用的建站、模型圖和驗收規格 |

## 用規則擴充網站

把 [AGENTS.md](AGENTS.md) 放在自己的專案根目錄。提供教材 PDF 或 GitHub 教材目錄，即可指定站名、配色和章節。規則定義章節版型、切換元件、來源標示和離線驗收。

本站以 3.1 為版型擴充 3.2 和 3.3。以 3.2 為例，共用同一份樣式與切換程式，新增章節頁後在首頁加入卡片。驗收包含首頁與章內連結、模型狀態對應和章末解析。下一次可用同一流程新增 3.4 多模態 AI 技術與應用。

## GitHub Pages

在儲存庫 **Settings → Pages** 選擇 **Deploy from a branch**，發布來源設為 `main` 和 `/ (root)`。部署完成後使用 Pages 顯示的網址檢查首頁、章節與教材。
