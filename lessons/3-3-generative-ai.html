模型圖與核心知識

生成式 AI（Generative AI）建模資料或條件分布，能產生文字、影像、聲音等樣本。鑑別式方法（Discriminative Method）通常直接學習輸入到標籤的關係。模型家族與應用任務可以交叉，例如生成式文字模型也能依提示做分類。

模式崩潰（Mode Collapse）會使 GAN 反覆產出少數類型。Wasserstein GAN（WGAN）以 critic 的實數分數估計分布差異，訓練仍須驗證樣本多樣性。VAE 的重建效果也受模型和資料限制。

文生圖（Text-to-Image）用文字條件引導生成。若需要維持指定輪廓、姿勢或構圖，可加入空間條件。編輯時以遮罩指定修改區域，驗收還要檢查遮罩外是否被影響。

提示工程（Prompt Engineering）安排任務、輸入與輸出格式。若資料需要即時更新，可接檢索或工具；微調（Fine-tuning）則可改變模型的任務行為。評估時分別量事實支持、格式符合、回應延遲和成本。

圖像可比較品質、多樣性與條件符合度。文字重疊分數如 BLEU／ROUGE 可以補充評估，事實仍需核對來源。企業上線應另外查驗授權、敏感資料、提示注入與深偽風險，並為高影響輸出安排人工審核。

練習題

第 1 題 · 模型辨識

自編模擬題

一個生成系統用模型 G 產生新樣本，再用模型 D 分辨樣本來自訓練資料還是 G。這是哪種訓練方法？

  1. 對抗訓練
  2. 逐步去噪
  3. 遮蔽語言建模
  4. 以提示控制格式

第 2 題 · 情境判斷

自編模擬題

公司要產出以文字描述控制的概念圖。工程師想從隨機噪聲開始，多步更新讓樣本成形。最符合哪一種方法？

  1. 詞袋統計
  2. 物件分類
  3. 擴散生成
  4. 從訓練集直接抽出一張圖片

自編模擬題

  1. 用預訓練知識猜測狀態
  2. 呼叫查詢工具並核對訂單和資料時間
  3. 提高溫度以增加答對機率
  4. 照抄任何工具結果，省略核對

考前 3 分鐘複習

  • VAE 取樣再解碼，GAN 讓 G 和 D 對抗。
  • 擴散由噪聲開始，逐步更新直到得到樣本。
  • 自迴歸依前文生成下一詞元；溫度影響取樣。
  • 提示設定當次任務，工具查證外部資訊。
  • ASR 與 TTS 的資料方向相反。
  • 分開檢查內容品質、證據、延遲、成本和授權。

第 1 題解析

正確答案 A。G 與 D 有對抗的訓練目標。

  1. G 生成，D 區分樣本來源。
  2. 逐步去噪是擴散模型的典型路徑。
  3. 遮蔽預測是語言預訓練目標。
  4. 提示控制影響當次輸出。

第 2 題解析

正確答案 C。擴散的典型反向生成流程反覆去噪，並可利用文字條件。

  1. 詞袋計數不生成圖像。
  2. 分類輸出通常是標籤或分數。
  3. 去噪與條件生成符合描述。
