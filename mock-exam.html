      第 12 題 · IoU 與匹配門檻

      答案 D · 理由 1　先把兩框共同的面積在聯集中只計一次，再比較各門檻。

      原題

      道路施工照片中，模型預測一個路障框。預測框面積為 90 平方像素，標註框為 110，重疊區為 80。兩框類別一致，沒有其他匹配候選。團隊在 IoU 至少 0.50 與至少 0.75 兩個設定下各評估一次。兩組設定只更換 IoU 門檻，不改預測框座標。這個預測在哪些設定可與標註配對？

      • A．兩個設定都可，因為重疊面積除以預測框面積約為 0.89。
      • B．兩個設定都可，因為類別一致時評估不用再判斷定位。
      • C．兩個設定都不可，因為重疊面積除以兩框面積總和等於 0.40。
      • D．只在 0.50 的設定可配對，因為 IoU 約為 0.67。

      計算過程

      1. 聯集 = 預測面積 + 標註面積 − 交集 = 90 + 110 − 80 = 120。
      2. IoU = 交集 ÷ 聯集 = 80 ÷ 120 = 2/3 ≈ 0.667。
      3. 0.50 ≤ 0.667 < 0.75，所以只通過 0.50 的設定。

      四個選項怎麼判斷

      • A．不符題意 IoU 的分母是聯集，不是預測框面積。
      • B．不符題意 類別相同還要符合給定的 IoU 條件。
      • C．不符題意 把交集重複算進總和，低估 IoU。
      • D．正確 聯集為 120，交集除以聯集約為 0.667。

      三個理由怎麼判斷

      • 1．正確 先把兩框共同的面積在聯集中只計一次，再比較各門檻。
        分母是 90＋110−80。
      • 2．不符題意 門檻升高會改變兩框本身的幾何重疊。
        它只改匹配判定。

      第 27 題 · SHAP 局部貢獻與模型尺度

      答案 B · 理由 2　局部貢獻與基準同尺度，先合計 log-odds，再用 Sigmoid 轉換。

      原題

      旅宿訂房的取消模型使用 SHAP 解釋某筆預測。工具說明各值可在正類 log-odds 尺度相加。基準值為 −0.8，提前天數貢獻 +1.1，訂金貢獻 −0.4，其他欄位合計 +0.1。主管想知道此筆輸出和哪個條件降低模型預測。同事提醒總分可能相同，但仍要保留每一項貢獻的方向，不可把特徵效應寫成因果結論。下列哪項正確？

      • A．模型取消率為 80%，因為兩個主要特徵相差 0.7 再加其他貢獻。
      • B．最終 log-odds 是 0，對應 50%；訂金對此筆模型輸出的局部貢獻為負。
      • C．最終 log-odds 為 −0.4，因為訂金是唯一降低取消率的特徵。
      • D．最終機率為 50%，因此訂金對此筆及所有資料都沒有影響。

      計算過程

      1. 總 log-odds = 基準 + 各特徵貢獻 = −0.8 + 1.1 − 0.4 + 0.1 = 0。
      2. 機率 = 1 ÷ (1 + e^(−log-odds)) = 1 ÷ (1 + e^0) = 0.5。
      3. 訂金的 −0.4 是這筆的局部負貢獻，不能讀成減少 0.4 個百分點。

      四個選項怎麼判斷

      • A．不符題意 0.8 是總貢獻，不是機率，也還沒有加基準值。
      • B．正確 所有貢獻與基準相加為零，訂金的局部貢獻為負。
      • C．不符題意 單一貢獻不能當最終輸出。
      • D．不符題意 總合為零可由不同方向抵銷，不能推論各項都無作用。

      三個理由怎麼判斷

      • 1．不符題意 先把每個 SHAP 值轉成機率，再把機率直接相加。

      • 3．不符題意 某欄位此筆為負就足以證明它是取消率下降的原因。
        局部歸因不等於因果。

      • C．將新版擴大至 20%，以更多流量判斷錯誤能否回到平均。
      • D．以小量真實流量量業務指標，現在依兩窗護欄切回舊版，修正並驗證後再試。

      計算過程

      1. 第 1 窗 1.1% > 1%，第 2 窗 1.4% > 1%。
      2. 連續兩窗同時滿足超標條件，因此觸發回退。
      3. 購票完成率觀察值差 8.4% − 8.1% = 0.3 個百分點，仍須獨立判斷樣本及不確定性。

      四個選項怎麼判斷

      • A．不符題意 影子結果未呈現給使用者，不能直接量新版改變的行為。
      • B．不符題意 事前回退規則已觸發，主指標不能替代護欄。
      • C．不符題意 超過試行規定，且持續曝露於已觸發護欄的版本。
      • D．正確 金絲雀能觀察實際使用，兩窗都已超過錯誤上限。

      三個理由怎麼判斷

      • 1．不符題意 只要離線指標改善，就可以略過回退條件。
        離線品質與線上可靠性各有要求。
      • 2．正確 使用者要接觸新版才能觀察實際業務反應，達到回退條件就先控制影響。
        需要事前固定判定方式。
      • 3．不符題意 影子請求可直接當成新版使用者已購票。
        影子只執行候選結果。

      第 47 題 · 依賴服務的斷路與降級

      答案 A · 理由 3　用依賴的連續失敗控制是否送出下一批請求，並保留降級輸出。

      原題

      門市查詢的加值評論服務連續逾時，卡住共用資源。產品可接受短時間省略評論，並希望等依賴恢復後再恢復呼叫。商品基本資料來自另一個正常的依賴，不能因為評論逾時也一起停用。哪個模式最直接提供「失敗時暫停、恢復時少量探測」？

      • A．斷路器，失敗累積到門檻時開路，之後透過半開狀態探測。
      • B．負載平衡器，平均分配門市查詢給前端副本。
      • C．自動擴展，在等待請求過多時增加 API 副本。
      • D．指數退避，為每個請求拉長各自的重試間隔。

      四個選項怎麼判斷

      • A．正確 與題設的停止及恢復流程相符。
      • B．不符題意 如果共用依賴仍失敗，前端分流無法判定何時停止呼叫。
      • C．不符題意 增加前端副本仍可能讓故障依賴承受更多呼叫。
      • D．不符題意 可減輕重試壓力，但不等於跨請求的開路和半開探測。

      三個理由怎麼判斷

      • 1．不符題意 單一請求加等待，就等同保護所有請求的故障狀態。
        斷路器維持依賴健康狀態。
      • 2．不符題意 只要擴大共用資源池，依賴失敗就不會影響其他路徑。
        仍可能被長時間掛起耗盡。
      • 3．正確 用依賴的連續失敗控制是否送出下一批請求，並保留降級輸出。
        恢復時只放少量探測。

      第 48 題 · 整體指標與地區子群

      答案 C · 理由 1　需要讓少數地區的誤差獨立可見，並且用實際到貨值驗證。

      原題

      理貨延誤模型的整體誤差穩定，但占比很低的偏遠地區抱怨增加。系統有地區標記，隔日可取得真實到貨時間。評估標籤與推論紀錄可用訂單 ID 配對，且已知各地區有效標籤數不同。若要確認模型是否只在這些地區退步，哪一個新增監控最切題？

      • A．把整體誤差改成每小時更新，不區分地區。
      • B．在模型訓練時記錄更多學習率與 loss。
      • C．依地區獨立計算有真值的預測誤差、樣本數與時間趨勢。
      • D．只比較各地區 API 延遲，作為預測偏差的替代。

      四個選項怎麼判斷

      • A．不符題意 提高頻率仍會把少數地區混在平均中。
      • B．不符題意 訓練遙測不能回答實際地區品質。
      • C．正確 以分群真值直接檢查偏遠地區的模型品質。
      • D．不符題意 服務速度與預測正確性有不同指標。

      三個理由怎麼判斷

      • 1．正確 需要讓少數地區的誤差獨立可見，並且用實際到貨值驗證。
        整體指標可留作概況。
      • 2．不符題意 投訴次數與模型誤差在任何條件下都可直接等同。
        投訴可能含其他原因且有選擇偏差。
      • 3．不符題意 整體誤差穩定就能排除小群體退化。
        少數群體會被大群體平均掩蓋。

      第 49 題 · 漂移與線上特徵偏差

      答案 B · 理由 1　先定位到同筆資料的特徵差異，再決定要不要檢查資料分布或重訓。

      原題

      門市缺貨模型上線一段時間後，線上表現下降。追查發現同一筆訂單，離線以「扣掉取消單後的近七天件數」計算，線上卻包含取消單；兩邊使用同一日期範圍。最近尚未發現輸入原始行為改變。新舊版本仍能在同一原始請求上重現這個差異。哪項診斷及修正最直接？

      • A．資料漂移，先調高輸入分布告警門檻。
      • B．訓練與服務偏差，統一特徵定義，再用同批原始資料逐筆比較線上和離線輸出。
      • C．概念漂移，立刻用近七天樣本重訓以適應購買習慣。
      • D．決策閾值偏移，改用更低的模型分數門檻即可。

      四個選項怎麼判斷

      • A．不符題意 已有同筆資料轉換不一致的證據，改告警不會修好欄位。
      • B．正確 同一原始事件在兩端使用不同轉換，應先修管線。
      • C．不符題意 尚無同樣特徵條件下目標關係改變的證據。
      • D．不符題意 門檻不會修正特徵定義。

      三個理由怎麼判斷

      • 1．正確 先定位到同筆資料的特徵差異，再決定要不要檢查資料分布或重訓。
        有比單看輸出更直接的管線證據。
      • 2．不符題意 只要線上成績下降，就可確定真實目標分布已改變。
        原因也可能是服務管線。
      • 3．不符題意 資料漂移一定會使同一筆原始輸入在兩端得到不同數值。
        漂移可在轉換一致時發生。

      第 50 題 · 多張圖片與請求格式

      答案 C · 理由 2　這個請求同時包含檔案及結構化資訊，需要能分欄承載兩種內容的本文格式。

      原題

      平板要一次送出三張設備照片和各自的序號。每張照片可達 5 MB。伺服器必須在同一請求中收到檔案與序號清單，回傳逐張分類結果。閘道允許傳送足夠大的請求本文，但限制網址與標頭長度。不同序號的照片可能同名，不能只靠檔名配對。哪個介面配置最合適？

      • A．將三張照片轉成 Base64，連同序號放入 GET 的查詢字串。
      • B．以 PUT 傳一份只有序號的 JSON，伺服器再從平板的本機路徑讀照片。
      • C．以 POST multipart/form-data 送多個檔案欄位及一個 JSON 序號清單，回傳逐張 JSON 結果。
      • D．將照片放進自訂標頭，只把序號清單放入本文。

      四個選項怎麼判斷

      • A．不符題意 照片可能超過網址限制，且網址紀錄可能留下內容。
      • B．不符題意 伺服器不能直接讀取平板本機檔案。
      • C．正確 不同表單欄位可同時承載二進位及中繼資料，需驗證序號與檔案的配對。
      • D．不符題意 大量二進位不適合放在受限的 HTTP 標頭。

      三個理由怎麼判斷

      • 1．不符題意 回應格式選 JSON，所以請求的三張照片也只能做成網址參數。
        請求與回應可使用不同格式。
      • 2．正確 這個請求同時包含檔案及結構化資訊，需要能分欄承載兩種內容的本文格式。
        伺服器需驗證個別欄位及配對關係。
      • 3．不符題意 只要伺服器知道平板檔名，就能在伺服器端讀到同一個檔案。
        檔名不能傳遞檔案內容。
