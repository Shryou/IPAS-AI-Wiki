# iPAS 中級 AI 應用規劃師圖解學習站

將 L21 講義改寫成可離線瀏覽的繁體中文網站。首頁收錄已完成的章節網頁，另設教材索引連結到九份 PDF。章節以圖解、重點比較和單選練習組織內容，解析放在章末。

## 開啟網站

雙擊根目錄的 `index.html`。首頁的「重點預覽」與章內圖解說明支援滑鼠懸停、鍵盤聚焦與手機點按。靜態網站以原生 HTML、CSS、JavaScript 製作，直接開啟即可使用。

| 位置 | 用途 |
| --- | --- |
| `index.html` | 首頁及章節索引 |
| `lessons/3-1-nlp.html` | 3.1 自然語言處理技術與應用，也是新增章節的版型 |
| `assets/` | 共用樣式與互動 |
| `outputs/` | 九份自製圖解精讀 PDF，也是 AI 編寫新章節的來源 |
| `AGENTS.md` | 建站、擴充和查核規則 |

## 擴充或另建自己的版本

把 [AGENTS.md](AGENTS.md) 放在自己的專案根目錄。可使用本專案的 `outputs/`，也可以在任務指令提供其他 PDF。自訂站名、配色和要做的章節，AI 依規則重用版型與互動元件。教材保留原始出處和章節頁碼。

例如「依照 AGENTS.md，使用 `outputs/` 的 3.2 講義，把電腦視覺技術與應用加入網站。」AI 應建立 `lessons/3-2-computer-vision.html`，在首頁加入 3.2 卡片及重點預覽，沿用共用的 CSS 和 JavaScript。實際驗證時，從首頁進入 3.2、操作章內目錄和解析，再返回首頁。

## GitHub Pages

在儲存庫 **Settings → Pages** 選擇 **Deploy from a branch**，發布來源設為 `main` 和 `/ (root)`。部署完成後，使用 Pages 顯示的網址開啟首頁，並測試章節、教材及樣式的相對路徑。
